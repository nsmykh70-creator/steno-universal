# PS18 — Word-Class Prediction: результаты испытаний

Концепция STENO-P7 Stage 14: Марковская модель порядка 2 над 7 классами
письма (Latin, Cyrillic, CJK, SEA, Indic, RTL, other), обучаемая на жадном
разборе входа словарём; сюрпризал переходов (1/64 байта, множитель w)
добавляется к стоимости рёбер DP-кодировщика. Модель не сериализуется.

Флаги бенча: `--cap 6000 --syll 5000` (воспроизводят PS17 побайтно:
baseline w=0 fb2 = кадр 19 434 439 Б, архив 7 900 725 Б против PS17 7 899 813,
разница — версия xz). Все 8 прогонов верифицированы полной распаковкой
(cmz-decode ×2 + pack + decode + cmp с исходником).

## Вывод

- На связном тексте (fb2) концепция **вредит**: архив хуже на 1.1–3.8%,
  кодирование медленнее на 22–31% (лишний жадный проход + DP в единицах
  1/64 байта). Причина: cmz2 (порядки 1–3 + match-модель) уже извлекает
  контекст токен-потока, классовая модель лишь искажает DP.
- На смешанных данных (m10) — **умерный выигрыш** ~0.8% при почти той же
  скорости: парсинг, «сглаженный» классовой моделью, даёт ctrl/data,
  которые cmz сжимает лучше, несмотря на больший кадр.
- По совокупности (текст — главный корпус, скорость) вариант **слабее
  PS17**; рекомендация — не включать w>0 в дефолт. Флаг `--wclass W`
  оставлен экспериментальной опцией; для смешанных входов возможен
  автоматический выбор между parse-вариантами по фактическому размеру
  архива (ценой двойного кодирования).
